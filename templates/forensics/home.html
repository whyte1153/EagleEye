How evidence is handled

  • Hashed on arrival: SHA-256 (and legacy MD5) are computed while the file is written.
  • Original preserved: stored under a random name, read-only, outside any web-served folder. Never modified or deleted by the app.
  • Working copy: analysis runs on a copy that is proven identical by hash, then discarded.
  • Type check: content signature vs file extension, to expose disguised files.
  • Chain of custody: every action is logged in a hash-chained, append-only record.
  • Not guaranteed: timestamps and other metadata can be altered by acquisition and upload; a hash proves the stored copy is unchanged since receipt, not before.
